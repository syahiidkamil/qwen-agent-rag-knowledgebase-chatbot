# TC-02-001: User browses the knowledge base and filters by tag

## Type
happy-path

## Preconditions
- Seeded user account (`cs.demo@airanext.id`) exists and is active.
- At least two documents are ingested.
- At least one of those documents has 2+ tags set by an admin via TC-02-002 (the user has no way to tag docs themselves).

## Steps
1. Sign in as user; land on `/workspace/ai-help`.
2. Click the **Knowledge base** entry in the workspace sidebar.
3. Observe the page header, the filter chip bar at the top (if any tags exist in the corpus), and the document table below.
4. Click a tag chip in the filter bar.
5. Click a second tag chip.
6. Click the "clear (N)" affordance.
7. Click a tag chip rendered inside one of the table rows (the in-row chips are also clickable).

## Expected Result
- The page renders read-only — no upload, delete, reingest, or rename actions are present.
- The table columns are: File · Tags · Indexed · Size.
- Only documents with `status = ingested` are listed; uploaded/ingesting/failed docs are hidden.
- The filter chip bar lists every distinct tag in the visible corpus, sorted alphabetically. The "Filter by tag" label sits to the left.
- Clicking a tag chip flips its `data-active` state. The visible row set narrows to docs whose `tags` includes at least one selected chip (OR predicate, exact match, case-folded).
- Clicking a second chip ORs the predicate (more rows visible, not fewer). Clicking the same chip again deselects it.
- The "clear (N)" affordance appears whenever ≥1 chip is selected and resets the selection in one click.
- Clicking a tag chip inside a table row toggles that tag in the filter bar (delegated click).
- If the corpus has zero tags, the filter chip bar is not rendered.

## Priority
high
