# TC-02-004: Sidebar collapse persists across reloads and across both shells

## Type
edge-case

## Preconditions
- Seeded super-admin account exists (the test only requires sign-in; both admin and user roles exhibit the same collapse behavior, so any role would work — super_admin makes it trivial to verify both shells).

## Steps
1. Sign in as super_admin; land on `/admin/cms`.
2. Click the sidebar toggle (chevron icon at the top of the sidebar).
3. Confirm the sidebar narrows to icon-only width.
4. Hard-reload the page.
5. Navigate from `/admin/cms` to `/admin/knowledge` and `/admin/users`.
6. Sign out and sign back in as the seeded user; navigate to `/workspace/ai-help`.
7. Click the sidebar toggle to expand.
8. Reload.

## Expected Result
- Step 2: sidebar collapses; toggle button icon flips from "collapse" to "expand"; the labels, section headers, badge counts, and user-card meta all hide; only icons remain.
- Step 4: collapsed state survives reload.
- Step 5: collapsed state survives in-app navigation (no relayout flash).
- Step 6: the workspace sidebar starts in the same collapsed state (one shared `localStorage["aira:ui:sidebar_collapsed"]` key across both shells).
- Step 7: expanding flips it back; localStorage key updates to `"0"`.
- Step 8: expanded state survives reload.

## Priority
low
