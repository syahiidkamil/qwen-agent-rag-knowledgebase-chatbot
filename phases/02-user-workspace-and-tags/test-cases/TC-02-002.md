# TC-02-002: Admin tags a document via the Edit document dialog

## Type
happy-path

## Preconditions
- Seeded admin (or super-admin) account exists.
- At least one document is ingested.

## Steps
1. Sign in as admin and navigate to `/admin/knowledge`.
2. Click the **Edit document** action (pencil icon) on an ingested row.
3. In the Edit document dialog, click the tag input.
4. Type `faq` then press Enter.
5. Type `tuition,` (with the trailing comma — comma also adds the tag).
6. Type `Cohort` then press Enter. Note the chip is rendered as `cohort` (case-folded).
7. With the tag input empty, press Backspace. Note the last chip is removed.
8. Re-add `cohort`. Click Save.
9. Observe the row in the table.

## Expected Result
- Each Enter or comma keystroke turns the input into a chip; the input clears for the next tag.
- Tags are case-folded to lowercase on add. Duplicate tags (case-insensitive) are silently dropped — entering `FAQ` after `faq` does not produce a second chip.
- Backspace on an empty input removes the most recently added chip.
- Each chip has an inline `×` button that removes it directly.
- The Save button is disabled until either the filename or the tag list differs from the persisted state.
- After Save, the table row's Tags column shows the three chips (`faq`, `tuition`, `cohort`).
- The Storage object and chunk count are unchanged.

## Priority
high
