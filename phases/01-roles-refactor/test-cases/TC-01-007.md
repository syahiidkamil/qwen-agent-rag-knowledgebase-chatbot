# TC-01-007: Deactivated user cannot sign in

## Type
edge-case

## Preconditions
- Seeded admin and seeded user accounts exist.
- The seeded user is currently active.

## Steps
1. Sign in as admin, navigate to the Users page.
2. Click Deactivate on the seeded user's row.
3. Confirm the status changes to `deactivated`.
4. Sign out.
5. Attempt to sign in at `/login` with the deactivated user's credentials.

## Expected Result
- The Users page reflects the deactivated status immediately.
- The deactivated user's sign-in attempt fails with a clear error (e.g. "This account is inactive. Contact your administrator.").
- The deactivated user never reaches any post-login surface.
- Reactivating the user (admin clicks Reactivate) restores sign-in.

## Priority
high
