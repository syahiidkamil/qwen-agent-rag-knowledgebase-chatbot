# TC-01-001: All three seeded roles can sign in

## Type
smoke

## Preconditions
- Seed script has been run against a fresh database.
- `SEED_SUPER_PASSWORD`, `SEED_ADMIN_PASSWORD`, `SEED_USER_PASSWORD` are set in the BE environment.
- Frontend is reachable; backend is up and `/health` returns ok.

## Steps
1. Navigate to `/login`.
2. Sign in with the seeded super-admin email and password.
3. Note the landing page after sign-in; sign out.
4. Sign in with the seeded admin email and password; note the landing page; sign out.
5. Sign in with the seeded user email and password; note the landing page; sign out.

## Expected Result
- All three sign-ins succeed (no error toasts, no 401s in the console).
- Super-admin and admin both land on the admin surface.
- User lands on the internal chat surface (NOT the admin surface).
- Sign-out from each session clears the session and redirects back to `/login`.

## Priority
critical
