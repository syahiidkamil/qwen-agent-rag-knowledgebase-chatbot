# TC-01-009: Admin cannot reach super-admin-only landing config

## Type
edge-case

## Preconditions
- Seeded admin and super-admin accounts both exist.
- Landing config has at least one previously-set value (e.g. a brand color).

## Steps
1. Sign in as the seeded admin.
2. In the FE sidebar, observe which navigation items are shown.
3. Manually type the Landing-config admin URL into the address bar.
4. Capture the admin's Bearer JWT and make `PUT /api/landing-config` with a small payload directly via `curl`.

## Expected Result
- The sidebar does NOT show the Landing-config item for an admin (only Knowledge base and Users).
- The Chat-mode toggle is also absent for admin.
- Typing the URL directly: either the route does not render and redirects to a "not authorized" view, or it renders read-only with an explanation, depending on implementation — but the admin cannot mutate the config.
- The direct `PUT /api/landing-config` call returns 403.

## Priority
high
