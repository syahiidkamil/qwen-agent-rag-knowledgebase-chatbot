# TC-01-012: Existing knowledge-base upload still works for admin (regression)

## Type
regression

## Preconditions
- Seeded admin account exists and is signed in.
- A small test document is available locally (e.g. a 1-2 page PDF).

## Steps
1. Sign in as admin and navigate to the Knowledge base page.
2. Click "Upload file" and select the test document.
3. Wait for the upload to complete; observe the document row appear with status `uploaded`, then transition to `ingesting`, then `ingested`.
4. Note the chunk count after ingestion.
5. Sign out and chat anonymously (chat mode = public) with a question expected to hit the new document.

## Expected Result
- Upload completes without error and the row appears immediately.
- Status transitions: `uploaded` → `ingesting` → `ingested` (or → `failed` with a visible error if ingestion legitimately fails for this document).
- Chunk count is non-zero on success.
- The newly-uploaded document's content is retrievable in a chat answer; the source chip references the new file.
- No regression in upload, ingestion, or retrieval behavior compared to the pre-refactor state.

## Priority
high
