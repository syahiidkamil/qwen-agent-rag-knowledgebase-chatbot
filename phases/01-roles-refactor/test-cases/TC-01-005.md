# TC-01-005: Admin creates a new user; that user can sign in

## Type
happy-path

## Preconditions
- Seeded admin (or super-admin) account exists.
- A throwaway email address is available (e.g. `cs.newhire+test@airanext.id`).

## Steps
1. Sign in as admin and navigate to the Users page.
2. Click "Add user".
3. Enter the throwaway email, a valid password (8+ chars), and select role = user.
4. Submit.
5. Observe the success toast / confirmation; sign out.
6. Navigate to `/login` and sign in with the new user's credentials.
7. Observe where the user lands.

## Expected Result
- The Add user dialog accepts the email + password + role selection.
- On submit, the dialog closes and a success message appears.
- The new user appears in the Users page list with role = user and status = active.
- The new user can sign in at `/login` and lands on the internal chat surface.
- The new user cannot see or reach the admin surface.
- Repeating steps 1–4 with role = admin or role = super_admin produces the same successful creation flow.

## Priority
high
