# TC-01-004: Admin deletes a document and every chunk is removed

## Type
happy-path

## Preconditions
- Seeded admin account exists.
- At least one ingested document exists with a non-zero chunk count (note the chunk count and document id from the documents list).
- Direct DB read access is available to verify chunk removal (or an admin endpoint that exposes chunk count for a given document).

## Steps
1. Sign in as admin and navigate to the Knowledge base page.
2. Note the chunk count for a target document.
3. Click the Delete action; confirm.
4. Observe the document list refresh.
5. Verify (via DB or admin endpoint) that the `chunks` table contains zero rows with `document_id = <deleted-id>`.

## Expected Result
- The document disappears from the documents list immediately.
- The `chunks` table has zero rows referencing the deleted document.
- The Storage object for the deleted document is also removed (or scheduled for removal — whichever the existing delete flow does today).
- No chunks belonging to other documents are affected.

## Priority
high
