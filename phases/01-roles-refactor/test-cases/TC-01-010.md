# TC-01-010: Super-admin cannot deactivate themselves via the UI

## Type
edge-case

## Preconditions
- Seeded super-admin account exists and is signed in.
- The Users page is reachable.

## Steps
1. Sign in as super-admin.
2. Navigate to the Users page.
3. Locate the super-admin's own row in the list.
4. Observe the Actions column for that row.

## Expected Result
- The super-admin's own row shows no Deactivate control (the column may be empty, may show a hyphen, or may show a tooltip explaining the restriction).
- All OTHER rows (admin, user) show the Deactivate (or Reactivate) control normally.
- If another super-admin exists, they CAN deactivate this one — the rule is "cannot deactivate self," not "no super-admin can ever be deactivated."

## Priority
medium
