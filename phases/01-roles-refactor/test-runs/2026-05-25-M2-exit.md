## Deviation Notes

### GET /api/documents — 200 for user-role (TC-01-008)

The original TC-01-008 expected `GET /api/documents` to return 403 for a user-role bearer. At M2, the spec explicitly introduced **read-relaxation** on this endpoint — user-role accounts are now permitted to read the document list (supporting the workspace KB view). The 200 response is correct M2 behavior, not a security regression. Write operations (`POST`, `DELETE`) remain 403 as required.
