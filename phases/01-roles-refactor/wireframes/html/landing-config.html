Interactions

  • Chat-mode radio → toggles selection only. Does NOT save until [Save changes] clicked.
  • [Save changes] → PUT /api/landing-config with full config blob. Toast + reset dirty on success.
  • Brand preset fields → free text inputs. Existing field set; no add/remove in this phase.

Notes

  • Both Chat mode AND brand presets live in landing_config.config JSONB. One save covers both.
  • chat_mode value: "public" | "internal". Default "public" if absent.
  • Backend gate: require_role("super_admin") on PUT /api/landing-config.
  • GET /api/landing-config stays publicly readable — the landing page fetches it anonymously.
