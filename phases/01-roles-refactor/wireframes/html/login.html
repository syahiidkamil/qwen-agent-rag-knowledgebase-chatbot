Login

Single sign-in surface for every role. After successful authentication, redirect by role.

Default state

/login

••••••••••
Sign in

No "forgot password" — out of scope this phase.

Other states

Submitting

Button shows spinner. Inputs disabled. Same layout, no popover.

Auth failed

Red inline error below the password field: "Wrong email or password." No toast, no modal.

Account deactivated

Same inline error position: "This account is inactive. Contact your administrator." Sourced from a specific Supabase error code, not a guess.

Account misconfigured (post-sign-in, role missing/unknown)

Inline error appears AFTER a redirect attempt fails: "This account needs setup. Contact your administrator." The session is cleared automatically.

Interactions

  • [Sign in] → supabase.auth.signInWithPassword. Then redirect by role:
    • super_admin / admin → /admin (lands on Knowledge base by default)
    • user → /workspace
    • missing / unknown role → sign out, render "Account misconfigured" inline
  • Pressing Enter in either field submits.
  • Email field auto-focuses on page mount.

Notes

  • Reuses existing login page DOM; behavior changes are purely in the post-sign-in branch.
  • No "forgot password", no "create account", no third-party SSO.
  • FE reads the role from the verified JWT for routing; backend re-verifies on every API call.
