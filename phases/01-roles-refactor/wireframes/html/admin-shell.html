Other states

Loading

Sidebar renders skeletons for the role chip while the session resolves; main panel shows a route-level spinner. ~200 ms ceiling.

Mid-deactivation by another admin

Next API call returns 401; FE clears the session and bounces to /login with a neutral "Your session has ended" inline message.

Interactions

  • Sidebar item click → react-router navigates; active item gets highlight.
  • [Sign out] → supabase.auth.signOut; clears auth store; redirects to /login.
  • Role chip under email is display-only.

Notes

  • Role gating in two places: sidebar render and route guard. Defense in depth.
  • "Aira Admin" wordmark is a future-design concern; current text is fine.
